Sishu Kishore — independent magazine repository

Public reading pages, locally stored artwork, full Odia fonts, ebook scans and reviewed text. Shalandi storefront is excluded.

Build: npm run build (Node 22+; no dependencies). Preview: python3 -m http.server 8766 --directory public.

Intended hostname: sishu.kabitawithoutborders.org
Editorial tools now use the independent Firebase project described in backend/README.md. This repository does not contain private accounts, submissions or credentials.

Imported from the approved combined-site commit bcdab2661c73bd1cba3cff9e64715c09cce4599c. Source snapshot and original printed covers remain preserved in the existing project. This repository has independent Git history; pushes to main now build, verify and deploy automatically through GitHub Actions to GitHub Pages.

Sharing: run scripts/prepare-sharing.py (BeautifulSoup and Pillow) after adding pages or changing art. Every HTML page has static Open Graph and Twitter metadata. Images are full-composition JPEG previews; pages without suitable artwork use the magazine cover. No author likeness is fabricated.

Homepage direction (user and editor feedback, 15 October 2026): show every current-issue article and every preserved children's drawing as an equally sized compact thumbnail with complete title and credit. Shuffle all homepage articles once per tab session, retaining the order on refresh and return from reading; do not select a subset or claim guaranteed equal exposure. Keep the current-issue page's larger cards, editorial order and reader sequence unchanged. The standalone art gallery retains larger drawings and full credits. Use ordinary responsive grids, not a three-item preview or sideways carousel; this supersedes the earlier homepage publication-order and three-preview guidance. Rebuild the home artwork section alone with scripts/build-children-art.py --home-only; its source is provenance/children-art/artworks.json.

Home and edition are separate pages: /shishu/ is the compact magazine overview; /shishu/current_issue.html is the current edition with larger illustrated contents and reader entry. The primary navigation must link to both, labelled ମୂଳ ପୃଷ୍ଠା and ଚଳିତ ସଂଖ୍ୟା respectively. scripts/build-magazine-navigation.py applies this shared header without changing page bodies and runs in the build. The cover continues to open the magazine reader directly.
