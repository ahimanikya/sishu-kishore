Sishu Kishore — independent magazine repository

Public reading pages, locally stored artwork, full Odia fonts, ebook scans and reviewed text. Shalandi storefront is excluded.

Build: npm run build (Node 22+; no dependencies). Preview: python3 -m http.server 8766 --directory public.

Intended hostname: sishu.kabitawithoutborders.org
Editorial tools now use the independent Firebase project described in backend/README.md. This repository does not contain private accounts, submissions or credentials.

Imported from the approved combined-site commit bcdab2661c73bd1cba3cff9e64715c09cce4599c. Source snapshot and original printed covers remain preserved in the existing project. This repository has independent Git history; pushes to main now build, verify and deploy automatically through GitHub Actions to GitHub Pages.

Sharing: run scripts/prepare-sharing.py (BeautifulSoup and Pillow) after adding pages or changing art. Every HTML page has static Open Graph and Twitter metadata. Images are full-composition JPEG previews; pages without suitable artwork use the magazine cover. No author likeness is fabricated.
