Install on your device

Open Editor Studio from your home screen or dock in its own window.

  • iPhone or iPad: open this page in Safari, tap Share, then Add to Home Screen. Keep Open as Web App enabled if shown.
  • Mac with Safari: choose File → Add to Dock.
  • Chrome or Edge: use the install icon in the address bar or the browser menu’s install option.

If your browser has no install option, you can continue using Studio in this tab.

Internet connection and editor sign-in required. Installing does not enable offline editing.
